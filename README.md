## 👨‍💻 Sobre mim

Olá! Sou Raul Ferreira Borges, desenvolvedor Full Stack e estudante de Desenvolvimento de Sistemas no IFSP.

Atualmente, trabalho como **Jovem Aprendiz Desenvolvedor Full Stack no ARQUIP (Arquivo Público Municipal)**, desenvolvendo ferramentas utilizando PHP e contribuindo para a evolução do Design System da instituição.

Tenho interesse em desenvolvimento de software, arquitetura de aplicações e criação de soluções que unam funcionalidade, organização e uma boa experiência de usuário.

Minha experiência envolve principalmente:

- Desenvolvimento de aplicações web Full Stack.
- Criação de ferramentas e funcionalidades utilizando PHP.
- Desenvolvimento de interfaces com React e Next.js.
- Automação de processos utilizando Python.
- Construção de aplicações web com Flask.
- Organização de código e desenvolvimento de componentes reutilizáveis.
